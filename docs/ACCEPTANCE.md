# G2 验收清单（指挥官亲验，不听 agent 自评）

> 原则：QA 报"通过"只代表它的检查项过了；我不重复跑它的脚本，**我跑它没跑的那部分**——尤其是"用户视角"和"能不能被部署"。

## A. 我自己动手跑的（不外包）

| # | 检查 | 命令 / 动作 | 通过标准 |
|---|---|---|---|
| A1 | 起得来 | `python3 -m http.server 8000` + `curl -sS -o /dev/null -w '%{http_code}'` | 200，且响应体含 H1 文案 |
| A2 | 子路径不炸 | 把站点临时放到 `/tmp/sub/tuxiaoyu/` 再从 `/sub/tuxiaoyu/` 提供服务 | 页面与全部资源 200（验证没有 `/` 开头的绝对路径） |
| A3 | 体积 | `wc -c index.html styles/*.css assets/js/*.js workers/*.js` | 合计 < 80KB |
| A4 | 零外链 | `grep -Rno 'https\?://'` | 只允许 GitHub 反馈链接与本站域名 |
| A5 | **CSP 兜底** | 检查 `<meta http-equiv="Content-Security-Policy">` 含 `connect-src 'none'` | 有。这是"零上传"唯一**技术上强制**的证据，比文案和静态审计都硬 |
| A6 | 无死链 | 从 index.html 抽所有本地引用逐个 curl | 全 200 |
| A7 | 404 兜底 | 访问一个不存在的路径 | 返回 404.html 或跳回首页，不是 GitHub 默认页 |
| A8 | 隐私自检文案 | 页面可见文本 | 含"打开开发者工具 / Network"这类教用户自己验的话 |

## B. 必须人工/真机验的（我做不了就写"未验证"，不许含糊）

| # | 检查 | 怎么验 | 谁验 |
|---|---|---|---|
| B1 | EXIF 方向 | 手机竖拍图（Orientation=6）压完不倒 | 用户（有手机） |
| B2 | 透明 PNG 转 JPG 铺白底 | 带透明通道的 logo 转 JPG | 用户 |
| B3 | 断网仍可压缩 | 加载页面后断网，再压一张 | 用户（最有说服力的一条） |
| B4 | 键盘全流程 | 只用 Tab/Enter/Space | 用户或 QA（需浏览器） |
| B5 | iOS Safari WebP 输出 | iPhone 上试"转 WebP" | 用户 |
| B6 | 移动端布局 | ≤720px 结果列表转卡片 | 用户 |

## C. 阻断项（任何一条不过，G2 不通过、不许上线）

1. A1/A2 不过 → 部署必然白屏，直接阻断。
2. A5 缺失 → "零上传"只是口号，不许上线。
3. A3 超预算 → 与 BRIEF 第 6 条冲突，打回。
4. B1/B3 明确坏掉 → 核心体验坏了，打回。
